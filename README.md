## Как проверялись работы

* Все 7 консольных лабораторных запускались в Node.js v22 — вывод и разбор результатов
  находятся внутри каждого файла (включая ответы на контрольные вопросы).
* Лаба №2: создан **настоящий git-репозиторий**, выполнены ветки, PR-слияния (`--no-ff`)
  и разрешение конфликта; лог сохранён в `laba2/git-demo-log.txt`.
* Лаба №7: копирование потоком сверено по размеру и sha256; в задании 3 намеренно показана
  ловушка с многобайтовыми символами на границе куска и её решение через `StringDecoder`.
* Лаба №8: сервер проверен самопроверкой `node laba8.js --selftest` — AJAX, long polling,
  SSE, JSONP и WebSocket отвечают корректно; React-приложение собрано и отдаётся сервером.
* Проект: автотест `npm --prefix backend run smoke` — **28 проверок, все проходят**:
  REST API, пагинация, валидация, серверные EJS-страницы, форма без JavaScript, вход в
  админку, защита CSRF, закрытость админки, отдача React-SPA. Тест проходит и на
  файловом хранилище (`DATA_DRIVER=json`), и на SQLite (`DATA_DRIVER=sqlite`).
* Интеграции проверены живьём: GitHub через официальный SDK `@octokit/rest` и погода
  Open-Meteo через собственный клиент поверх `fetch`; при недоступности сети отдаются
  кэш/заглушка и страница продолжает работать.

## Кратко о проекте 

* **Публичная часть:** React SPA (`/`) + серверные страницы на шаблонизаторе EJS (`/site/`).
* **Админка:** `/admin/login` — закрыта паролем, cookie-сессия, bcrypt-хеш пароля, CSRF-токены.
  Логин `admin`, пароль `admin123` (меняется в админке).
* **Данные:** галерея, новости и сообщения хранятся в файле `data/db.json`
  (или в SQLite при `DATA_DRIVER=sqlite`).
* **Архитектура:** чистая/луковая (порты и адаптеры) + MVC в слое представления.
  Обоснование — `project/README.md`, раздел 3.
* **Шаблонизатор:** EJS (обоснование и сравнение с Pug/Handlebars/Nunjucks — раздел 4).
* **Самодельные контролы:** `Carousel` (карусель галереи с drag-and-drop и клавиатурой)
  и `StarRating` (оценка сайта, ARIA radiogroup) — раздел 6.
* **Интеграции:** официальный SDK `@octokit/rest` (GitHub) и клиент поверх `fetch`
  (Open-Meteo), с кэшем на 10 минут и корректной деградацией — раздел 5.
