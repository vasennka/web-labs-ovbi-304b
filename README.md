# Лабораторные работы №1–8 и проект (JavaScript / Node.js / React)

Работы выполнены и проверены запуском. Каждая лабораторная — отдельный файл,
в конце файла приведены письменные ответы на контрольные вопросы.

## Состав

| Файл / папка | Что это |
|---|---|
| `laba1.js` … `laba8.js` | Лабораторные работы №1–8 (код, примеры запуска, ответы на вопросы) |
| `laba2/` | Модули лабораторной №2 «Анализ успеваемости»: данные, отчёт, функции участников |
| `laba8/` | Задание 1 — React-приложение (`progress-app/`), задания 2–3 — страницы `public/*.html` |
| `project/` | Проект «Фотостудия PRISMA»: backend (Node.js + Express + EJS) и frontend (React). Документация — `project/README.md` |
| `ОТЧЁТ по проекту — сайт фотостудии PRISMA.docx` | Отчёт по проекту: описание, архитектура, самодельные контролы, интеграции и 15 скриншотов сайта |
| `ОТЧЁТЫ-по-лабораторным/` | Восемь отчётов Word (по одному на работу): задание, код, скриншоты вывода, ответы |
| `ОТЧЁТ по лабораторным работам 1-8 (для сдачи).docx` | Сводный отчёт по всем восьми работам |
| `ЗАПУСК/` | Ярлыки для запуска лабораторных и сервера проекта (двойной клик) |
| `package.json` | `npm install` ставит зависимость `ws` для WebSocket в лабораторной №8 |

## Запуск

**Самый простой способ — ярлыки из папки `ЗАПУСК`** (двойной клик):

| Ярлык | Что делает |
|---|---|
| `Запустить лабу 1.cmd` … `Запустить лабу 7.cmd` | запускают соответствующую лабораторную работу |
| `Запустить лабу 8 (сервер).cmd` | поднимает сервер лабораторной №8 (http://localhost:3000) |
| `Установить проект (запустить один раз).cmd` | **запустить после скачивания**: ставит зависимости, создаёт базу с данными, собирает React-приложение |
| `Запустить проект (сервер).cmd` | запускает сайт проекта (http://127.0.0.1:4000), при первом запуске сам всё подготовит |
| `Проверить проект (автотест).cmd` | запускает 30 автоматических проверок проекта и печатает отчёт |

Порядок для проекта: `Установить проект (запустить один раз).cmd` → `Запустить проект (сервер).cmd`.

**Те же команды вручную:**

```bash
# лабораторные №1–7
node laba1.js
node laba2.js
node laba3.js
node laba4.js
node laba5.js
node laba6.js
node laba7.js

# лабораторная №8: сервер с заданиями 1–3 на http://localhost:3000
npm install
node laba8.js

# проект: сайт на http://127.0.0.1:4000 (админка /admin/login, логин admin, пароль admin123)
cd project
npm run install:all              # зависимости backend и frontend
npm --prefix backend run seed    # база с демонстрационными данными
npm run build                    # сборка React-приложения
npm start                        # запуск сервера
```
