## Как связаны с проектом

Тема №2 дополнительно разобрана **с привязкой к коду нашего проекта** —
см. [`../project/DOKLAD.md`](../project/DOKLAD.md): там те же идеи (порты и адаптеры,
правило зависимостей, REST-эндпоинты, монолит vs микросервисы) показаны на реальных файлах
`project/backend/src/**`.

Остальные темы тоже «ложатся» на проект, и на защите это удобно показать:

| Тема | Что показать в проекте |
|---|---|
| 1. MVC/MVP/MVVM | админка на MVC (маршрут → контроллер → EJS), публичная часть на React: «UI = f(state)», хук `useApi` как замена view-model |
| 2. Архитектура backend | `container.js` (composition root), смена `DATA_DRIVER=json/sqlite` без правок сервисов |
| 3. REST/GraphQL/gRPC | `/api/v1/*`, единый формат `{ok, error, details}`, пагинация, алиас `/api` с `Deprecation` |
| 4. Аутентификация | вход в админку: bcrypt-хеш, cookie-сессия `httpOnly`+`sameSite`, `session.regenerate()`, лимит попыток |
| 5. OWASP | CSRF-токены, `helmet` + CSP, белый список MIME при загрузке файлов, отсутствие `innerHTML` с пользовательскими данными |
| 6. Тестирование | `npm --prefix backend run smoke` — 28 интеграционных проверок; автотесты внутри лабораторных |
| 7. Статический анализ | примеры конфигов ESLint/dependency-cruiser из доклада можно применить к `project/backend/src` — правила слоёв уже соответствуют структуре папок |

## Про «тему 25»

В приложенных файлах темы под номером 25 нет: список докладов содержит 7 тем, а номер,
судя по заданию, взят из общего списка курса. Поэтому:

* если вам нужен **проект** — он выполнен по ТЗ и раскрывает архитектуру и REST API
  (`project/`, доклад — `project/DOKLAD.md`);
* если нужен **доклад по любой из 7 тем** — выбирайте любой файл из этой папки;
* если преподаватель назовёт формулировку темы 25 — скажите её, и я адаптирую
  соответствующий доклад (содержание и примеры переписываются быстро, структура уже готова).
