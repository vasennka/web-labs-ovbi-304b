║  ВАЖНО: ПОЧЕМУ ДВОЙНОЙ КЛИК ПО laba1.js ДАЁТ ОШИБКУ «Syntax error»        ║
╚══════════════════════════════════════════════════════════════════════════╝

Если вы дважды щёлкнули по файлу laba1.js (и любому другому labaN.js), Windows
запускает его НЕ через Node.js, а через старый движок «Windows Script Host»
(JScript). В нём нет современного синтаксиса JavaScript — отсюда окно с ошибкой:

    Script:  ...\laba1.js
    Line:    29
    Error:   Syntax error
    Code:    800A03EA    ← 800A03EA = «движок не понял синтаксис JS»

Это не ошибка в лабораторной работе. Лабораторные написаны для Node.js v18+.

══════════════════════════════════════════════════════════════════════════
СПОСОБ 1 (самый простой) — запускать ярлыками из папки «ЗАПУСК»
══════════════════════════════════════════════════════════════════════════

Рядом лежит папка «ЗАПУСК». Двойной клик по файлу внутри неё:

    Запустить лабу 1.cmd  …  Запустить лабу 7.cmd   — по одной работе
    Запустить ВСЕ лабы 1-7 и сохранить вывод.cmd    — сразу все 7;
        вывод каждой сохраняется в файл «вывод_лабаN.txt» в главной папке
    Запустить лабу 8 (сервер).cmd                   — сервер лабораторной №8
    Проверить лабу 8 (без браузера).cmd             — автопроверка транспортов
    Установить проект (запустить один раз).cmd      — зависимости проекта
    Запустить проект (сервер).cmd                   — сайт на http://127.0.0.1:4000
    Проверить проект (автотест).cmd                 — 28 автотестов проекта
    Демонстрация Git (лаба 2).cmd                   — настоящий git-флоу
    Открыть инструкцию.cmd                          — инструкция + папка с Word-докладами

Окно консоли не закроется само: в конце нужно нажать любую клавишу.

══════════════════════════════════════════════════════════════════════════
СПОСОБ 2 — запускать из командной строки (по методичке)
══════════════════════════════════════════════════════════════════════════

1. Откройте «Командную строку» (Win+R → cmd → Enter).
2. Перейдите в папку с работами:

     cd /d "C:\Users\Vasenka\Desktop\проектирование веб сайт"

3. Запустите нужную работу командой node:

     node laba1.js
     node laba2.js
     ... и так далее

Проверить, что Node.js установлен: команда  node -v  должна вывести версию (v18+).
Если Node.js нет — скачайте LTS-версию с https://nodejs.org/ и установите
(галочку «Add to PATH» оставьте включённой).

Совет: чтобы вывод попал в файл (для отчёта или скриншота), пишите
     node laba1.js > вывод_лаба1.txt

══════════════════════════════════════════════════════════════════════════
СПОСОБ 3 (необязательный) — научить Windows открывать .js через Node.js
══════════════════════════════════════════════════════════════════════════

В папке «ЗАПУСК» есть файл «Сделать двойной клик по .js рабочим.cmd».
Щёлкните по нему ПРАВОЙ кнопкой → «Запуск от имени администратора».

После этого двойной клик по laba1.js будет запускать Node.js, а не Windows
Script Host. Вернуть как было (если понадобится):

     assoc .js=JSFile
     ftype JSFile="C:\Windows\System32\WScript.exe" "%1" %*
