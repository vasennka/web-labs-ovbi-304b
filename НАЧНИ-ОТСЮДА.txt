1. ЧТО СДАВАТЬ ПРЕПОДАВАТЕЛЮ (уже готово, ничего запускать не нужно)
═══════════════════════════════════════════════════════════════════════════════

  ОТЧЁТ по лабораторным работам 1-8 (для сдачи).docx     ← главный документ
        в нём: по каждой лабораторной — задание, ключевой код,
        СКРИНШОТ реального вывода программы и письменные ответы
        на все контрольные вопросы (18 скриншотов внутри).

  doklady\word\                                          ← доклады по темам
        00-ukazatel-dokladov.docx   — указатель, как выбрать тему
        01 ... 07                   — все 7 тем из списка докладов
        08-arhitektura-s-primerami-proekta.docx — доклад по проекту

  project\                                                ← сам проект (сайт)
        описание и обоснования — project\README.md
        доклад по архитектуре   — project\DOKLAD.md

  Файлы .docx открываются в Word, LibreOffice Writer, Google Документах
  и Word Online. Если Word не установлен — откройте через Google Документы.

2. КАК ЗАПУСТИТЬ ЛАБОРАТОРНЫЕ (если преподаватель попросит показать вживую)
═══════════════════════════════════════════════════════════════════════════════

  Самый простой способ — ОДИН файл в этой папке:

        ЗАПУСТИТЬ-ВСЁ.cmd          (двойной клик)

  Он запустит лабораторные 1–7, сохранит вывод каждой в файл
  «вывод_лабаN.txt», затем проверит лабораторную 8 и откроет папку.

  Отдельные работы — ярлыки в папке «ЗАПУСК»:
        Запустить лабу 1.cmd  ...  Запустить лабу 7.cmd
        Запустить лабу 8 (сервер).cmd      — сайт на http://localhost:3000
        Установить проект (запустить один раз).cmd
        Запустить проект (сервер).cmd      — сайт на http://127.0.0.1:4000
        ВЫЛОЖИТЬ НА GIT (заполнить и запустить).cmd  — выложить на GitHub

  Из командной строки то же самое делается так:
        cd /d "C:\Users\Vasenka\Desktop\проектирование веб сайт"
        node laba1.js          (и так для каждой работы)

3. ЕСЛИ ДВОЙНОЙ КЛИК ПО laba1.js ДАЁТ ОШИБКУ «Syntax error 800A03EA»
═══════════════════════════════════════════════════════════════════════════════

  Так Windows открывает .js своим старым движком (Windows Script Host),
  а не Node.js. Это НЕ ошибка в работе. Запускайте файлы так:

    • двойным кликом по ярлыкам из папки «ЗАПУСК» (или ЗАПУСТИТЬ-ВСЁ.cmd), либо
    • из командной строки: node laba1.js

  Подробнее — файл ПРОЧТИ_ЕСЛИ_ЛАБЫ_НЕ_ЗАПУСКАЮТСЯ.txt
